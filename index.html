Digital Output Logic

Blinking of LED Using Arduino

EXP 01

Objective: Learn GPIO digital switching by regulating forward voltage across a diode using sequential programmatic state delays.

Components Arduino Uno, LED, 220Ω Resistor, Breadboard
Key Principle Active-high GPIO output mode with pulsed delay cycles 
const int ledPin = 13;
void setup() {
  pinMode(ledPin, OUTPUT);
}
void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
